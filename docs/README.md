## বর্তমান অবস্থা (২০২৬-১০-১০)

- ড্যাশবোর্ড (React) ১০টা পেজ (রিপোর্টসহ) + লগইন পেজ; মোবাইল অ্যাপ (Expo) রিপোর্ট পেজ ছাড়া একই ফিচার, সাথে অফলাইন আউটবক্স। দুটোতেই "নমুনা মোড" (সার্ভার ছাড়া সিমুলেটর) আর লাইভ মোড (API)।
- REST API ও PostgreSQL তৈরি (`backend/`; টেলিমেট্রি TimescaleDB হাইপারটেবিলে), ডকারে পুরো সিস্টেম এক কমান্ডে চলে।
- লগইন চালু: JWT + রিফ্রেশ টোকেন, ইমেইল-পাসওয়ার্ড বা Google; তিন ভূমিকা (মালিক, অপারেটর, দর্শক), অনুমতি সার্ভারেই কার্যকর।
- ভাষা: বাংলা (ডিফল্ট) ও ইংরেজি, i18next দিয়ে, দুই ক্লায়েন্টেই।
- ডিভাইস (বা সিমুলেটর) সরাসরি `POST /api/v1/telemetry`-তে ডেটা পাঠাতে পারে (চাবি সেট থাকলে `X-Device-Key`); লাইভ মোডে পাম্প-সেচের কমান্ড API-তে যায়।
- সার্ভারেই চলে: নিয়ম ইঞ্জিন (অটো সেচ, সময়সূচি, বৃষ্টি ও ট্যাংকের নিয়ম, পাম্পের দৈনিক সীমা), সতর্কতা + টেলিগ্রাম ও SMS, সাপ্তাহিক সারসংক্ষেপ, আবহাওয়া (Open-Meteo)। মালিকের জন্য ব্যবহারকারী ব্যবস্থাপনা ও অডিট লগ।
- ফলন, পানির ব্যবহার (পাম্পের সময় × প্রবাহ) আর প্রতি কেজিতে লিটার মাপা হয়; পরের ফসলের পরামর্শ কারণসহ। বাকি কাজ: [06](06-roadmap.md)।
- ESP32 ফার্মওয়্যার ও MQTT ব্রিজ এখনো বানানো হয়নি; ডিভাইস কমান্ড শুধু ডাটাবেসে।
